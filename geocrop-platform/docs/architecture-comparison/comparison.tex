{\normalsize\bfseries Why it is faster, in short}
\begin{itemize}\setlength{\itemsep}{1pt}
  \item \textbf{Send only what is visible.} Tiles replace whole files, so data per screen stays small as images and models grow.
  \item \textbf{Keep results as rasters.} A pixel map is far smaller than polygons and needs no conversion.
  \item \textbf{Do heavy work in the background.} Queued workers run models; the website never waits.
  \item \textbf{Cache repeated work.} Nginx keeps tiles that were already drawn.
  \item \textbf{Draw with the GPU.} MapLibre renders tiles with WebGL instead of thousands of shapes.
\end{itemize}
