\sect{How the metrics are used}
\begin{itemize}\setlength{\itemsep}{1pt}
  \item \textbf{Cost per unit of result:} ms per 1,000 pixels, KB per screen, seconds per AOI, so the prototype and the platform are directly comparable.
  \item \textbf{Old against new:} the 130$\times$ data reduction and 1,021 ms JSON parse against 47 ms tiles are reported side by side.
  \item \textbf{Median and p95,} not only averages, to reflect real use.
  \item \textbf{Resource analysis:} time, peak RAM and storage are measured for every workflow stage and repeated for each new model.
\end{itemize}
